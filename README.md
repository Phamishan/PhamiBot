# PhamiBot - Discord bot for Phamishan & friends

## Commands

```
🤖 - /commands
Overview of all commands.

🤣 - /placeholdermeme
Sends a random placeholder meme.

📜 - /server
Server info.

🔫 - /valrank
Finds VALORANT profile, e.g. PH4M1#SH4N

👨‍👦‍👦 - /valrankfriends
Finds VALORANT profile (ONLY OG PLACEHOLDER & PREMIUMHOLDERS)

🫵🏾 - /me
Finds YOUR VALORANT profile (ONLY OG PLACEHOLDER & PREMIUMHOLDERS)

👨‍👨‍👦‍👦 - /premierteam
Finds Premier teams, e.g. PlaceHoldia#PLH

💰 - /bundles
Finds current VALORANT bundle(s)

📅 - /season
Shows the current VALORANT episode and act

➕ - /addserver
Add a Minecraft server to the list

👀 - /checkserver
Overview of all Minecraft servers

➖ - /deleteserver
Remove a saved Minecraft server (PH4M1 ONLY :P)

🪂 - /apexrank
Finds Apex Legends profile, e.g. PH4M1 (ENTER EA ACCOUNT NAME)

👨‍👦‍👦 - /apexrankfriends
Finds Apex Legends profile (ONLY OG PLACEHOLDER & PREMIUMHOLDERS)

🗺️ - /maprotation
Finds the current and next map [RANKED] (Apex Legends)

```
